    The TI-74 has its own key combinations. SHIFT modifies characters; FN accesses the BASIC keywords printed above the letters. You can also hold Shift on your keyboard. The program editor handles these combinations automatically when sending BASIC text with symbols. ENTER confirms commands: to run a program, press RUN, then ENTER. In CALC mode, use SHIFT + ENTER for =.

    The program editor is a separate text editor. Save .bas exports its text; Save state preserves the actual TI-74 memory. Saving a state provides a local alternative to cassette storage, which is not yet emulated.

    Technical status and diagnostics

    Implemented: TMS7000 instructions used by the TMS70C46, internal RAM, 8 KiB of RAM, ROM banking, timer, interrupts, keyboard matrix, and HD44780 LCD with CGRAM. ROM cartridges up to 32 KiB can be loaded.

    Verified with ROMs 55A2F7C0 / 019AAA2F: startup, calculations in BASIC and CALC modes, FOR/NEXT programs, saving and restoring states, and RAM retention across OFF/ON. Full compatibility has not been certified. The included diagnostic is a small original machine-code program without BASIC; it displays the row and bitmask of the last key pressed.

    Limitations: the slow-memory clock divider, DOCK-BUS peripherals, and RAM cartridges are not implemented. Speed 1× corresponds to 4 MHz / 2 without that divider. The built-in LCD font is approximate; load a 4,096-byte HD44780 A00 character ROM for the original glyphs. Emulation pauses when this page is hidden.
